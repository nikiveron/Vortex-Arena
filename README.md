# 🚀 Vortex Arena - космический аркадный экшен

**Статус:** ✅ Завершённый прототип   
**Жанр:** Аркадный шутер с видом сверху    
**Платформа:** Windows    
**Движок:** Unity  


![](https://github.com/nikiveron/Vortex-Arena/blob/main/GitHubPreview/Short_gameplay_preview.gif)

## 📥 [Скачать игру](https://github.com/nikiveron/Vortex-Arena/releases/tag/1.00) 

## 🧩 Описание

Проект представляет собой прототип космической аркадной игры, в которой игрок управляет кораблём, сражается с волнами врагов на ограниченной арене, набирает очки и старается продержаться как можно дольше.

Основной акцент сделан на реализации базовых игровых механик, модульной архитектуре кода, отзывчивом управлении, визуальных и звуковых эффектах, а также корректной работе пользовательского интерфейса на различных разрешениях экрана.


## 📦 Стек технологий

- Язык программирования: **C#**
- Игровой движок: **Unity**


## 🎮 Основной функционал

### 🚀 Игровой процесс
- Управление космическим кораблём с физикой
- Перемещение, ускорение, повороты и стрельба
- Система здоровья корабля
- Система уничтожения врагов и начисления очков
- Ограниченная игровая арена с физическими границами
- Спавн врагов через порталы
- Объекты восстановления здоровья

### 👾 Враги
- Несколько типов вражеских кораблей
- Различное поведение и атаки

- Главное меню

- Игровой UI:

## 🎨 Визуальное и звуковое оформление

- Различные модели кораблей
- Particle System:
  - Эффекты выстрелов
  - Взрывы кораблей
  - Космический туман (границы арены)
  - Эффекты повреждения и восстановления
- TextMeshPro для чёткого отображения текста
- Звуковые эффекты:
  - Выстрелы
  - Столкновения
  - Взрывы
  - UI-кнопки
  - Завершение игры


## ⚙️ Архитектура и технические решения

- Компонентный подход
- Модульная и расширяемая структура кода
- Событийная модель взаимодействия систем
- Слабая связность между игровыми компонентами
- Чёткая иерархия объектов на сцене
- Говорящие имена ресурсов и объектов

### ⏱️ Системы времени
- **GameTimer** — отслеживает чистое игровое время (без учёта меню)
- **PauseManager** — управляет паузой без нарушения логики игры


## 📌 Планы на развитие

- Эффекты повреждений с постепенным затемнением экрана при низком здоровье
- Система случайных событий на арене:
  - Астероиды
  - Временные бустеры и другое
- Добавление нескольких музыкальных треков
- Выбор скина корабля игрока
- Система сохранения рекордов с шифрованием данных для защиты от простого редактирования
